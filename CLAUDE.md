Este repositorio publica el Panel Cenzontle (`index.html`) y el portal del cliente (`portal.html`) en GitHub Pages: https://cenzontle024-dot.github.io/panel/

La guía completa del sistema está en el repositorio privado `cenzontle`, archivo `CLAUDE.md` (en la computadora: `C:\Cenzontle\cenzontle\CLAUDE.md`). Léela antes de hacer cambios.

Reglas rápidas:

- Comentarios en español dentro de cada función.
- Este repositorio es público: nunca agregues contraseñas, tokens ni datos de clientes.
- Prueba en el modo demostración antes de hacer push.
